# Programming101
「玩電玩學程式」範例程式

# 課程網站
http://moocs.nccu.edu.tw/course/17/introduction/

# 台北101 即時 3D 微縮模型
`taipei101/index.html`：以 Three.js 製作的台北 101 網頁 3D 模型，依台北時間即時計算太陽位置變換日夜，夜間依星期點亮當日燈色；按「跨年」可模擬倒數與煙火（每年 1 月 1 日 00:00 也會自動施放）。直接用瀏覽器開啟即可（需連網載入 Three.js）。

# 淡水漁人碼頭 即時 3D 微縮模型
`tamsui/index.html`：情人橋、情人塔（觀景艙會升降旋轉）、漁港漁船、木棧道與對岸觀音山。依淡水的太陽位置即時變換日夜，面板顯示當天日落時間，按「看夕陽」可從日落前 25 分鐘以 1 秒 = 1 分鐘播放。

# 九份老街 即時 3D 微縮模型
`jiufen/index.html`：面海山城地形、豎崎路石階、基山街、阿妹茶樓、基隆山與基隆嶼。依九份的太陽位置即時變換日夜，天一暗紅燈籠自動點亮；按「霧雨」可切換九份常見的霧雨天氣。

# 平溪天燈 即時 3D 微縮模型
`pingxi/index.html`：十分老街與穿街而過的平溪線火車、靜安吊橋、基隆河山谷。四色天燈會自動升空隨風飄移，入夜後燭光點亮；可按「放一盞天燈」或「元宵祈福」一次放 120 盞。火車約每 80 秒一班，經過老街時暫停放天燈。
